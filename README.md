# AttendX-Test-Scripts

## Project Description
This repository contains demonstration test scripts for the AttendX student attendance application.

## Test Scripts

### 1. test_login.py
Testing for valid credential inputs and empty username validation.

### 2. test_attendance.py
Testing for valid attendance status validation for Present, Absent, and an invalid status.

## Technology Used
- Python
- Git
- GitHub

## Purpose
To demonstrate version control of QA test scripts using Git and GitHub.
